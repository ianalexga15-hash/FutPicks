# FutPicks Frontend

SPA (Single Page Application) sin frameworks — HTML + CSS + JavaScript vanilla.

## Estructura

```
FutPicks_Frontend/
├── index.html       ← Shell de la app (nav + contenedor)
├── css/
│   └── style.css    ← Diseño completo (dark theme, glassmorphism)
├── js/
│   └── app.js       ← Toda la lógica de vistas y navegación (~2000 líneas)
└── images/
    ├── leagues/     ← Logos de ligas
    └── teams/       ← Logos de equipos
```
